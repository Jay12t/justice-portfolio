# Justice Oti-yeboah | Engineering Portfolio

A responsive personal portfolio focused on electrical and electronics engineering, programming, and practical technical problem-solving.

## What's included

- Responsive layout for desktop and mobile
- Introduction, current learning areas, projects, approach, and contact sections
- Interactive Ohm's law calculator
- Interactive power and energy calculator
- Semantic HTML, visible keyboard focus, and reduced-motion support
- No build tools or package installation required

## Run locally

1. Download or clone this repository.
2. Open index.html in a modern browser.
3. Open either calculator from the Projects section.

Alternatively, run a local server from the repository folder with Python's built-in server: python -m http.server 8000, then visit localhost port 8000 in your browser.

## Technical notes

The calculators are educational tools for idealised calculations. They do not replace engineering review, calibrated measurements, equipment specifications, or electrical safety procedures. The power and energy calculator uses P = V × I and estimates energy as E = P × t.
