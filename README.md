## Engineering tools

### Ohm's law
Use known electrical quantities to solve for the missing value:
- (V = IR)
- (I = V/R)
- (R = V/I)

### Power and energy
Explore the common power relationships for a resistive DC load:
- (P = VI)
- (P = I^2R)
- (P = V^2/R)

Energy can be estimated from power and operating time: (E = Pt).

### Class A and Class AB amplifier lab
Compare an illustrative common-emitter Class A stage with a complementary push-pull Class AB output stage. The lab is intended for learning circuit concepts; it is **not a transistor-level simulator or a construction-ready design**. Component selection, biasing, thermal analysis, distortion performance, and safety must be independently engineered before building a real circuit.

### Electrical machines and energy conversion
Explore core equations used for induction motors, rotating machinery, transformers, and efficiency calculations. The tools use idealised assumptions where stated and should be checked against course references and real machine data.

## Run locally

1. Clone or download this repository.
2. Open `index.html` in a modern browser.
3. Open any tool from the Projects section.

Or start a local server in the repository directory:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.
