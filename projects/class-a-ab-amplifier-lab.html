How to reason about amplifier efficiency

1. Output power

For a sinusoidal voltage across a resistive load, first estimate RMS output voltage:

Vᵣₘₛ = Vₚₑₐₖ / √2

Then:

Pout = Vᵣₘₛ² / Rₗ

2. DC input power

Use the DC supply voltage and the average current drawn from it:

Pdc = VCC × IDC(avg)

For real measurements, measure supply current under the same operating condition as the output-power measurement.

3. Efficiency

η = (Pout / Pdc) × 100%

Efficiency compares useful AC output power with DC power drawn. The rest becomes heat and other losses. Never assume a theoretical maximum is the measured result.

4. Class A vs Class AB

  • Class A: the active device conducts for the full 360° cycle. It is simple and can be linear, but its quiescent current causes continuous dissipation.
  • Class AB: complementary devices share the waveform with a small bias so both conduct slightly around zero. This reduces crossover distortion compared with Class B, while usually improving efficiency over Class A.

Important limitation: This is an educational visual model, not a transistor-level SPICE simulation or a verified amplifier design. Its efficiency figures are idealised estimates based on simplified assumptions. Actual efficiency depends on topology, bias current, device drops, signal level, clipping, thermal design, and power-supply losses. Do not build or connect hardware from this diagram alone.
